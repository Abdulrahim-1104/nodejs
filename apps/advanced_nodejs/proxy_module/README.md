# What is Proxy

- Proxy is a role/function that act as a server and sit between the client and the server to handle requests and responses
- Its hide the end server from the client
- A proxy is an intermediary that forwards communication between two parties

# Types of Proxy

- Forward Proxy
- Reverse Proxy

# What is Forward Proxy

- Represents the client. It sits between clients and external servers.

# What is Reverse proxy:

- Represents the server. It sits between external clients and backend servers

## Forward proxy

- The proxy stands on the client's side.

- The client says:

"I don't want to communicate with the internet directly. Proxy, communicate with it on my behalf."

## Reverse proxy

- The proxy stands on the server's side.

- The server owner says:

"I don't want clients communicating with my backend servers directly. Proxy, receive their requests on my behalf."
